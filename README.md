# 👥 User Management System (C# Console App)

A simple and clean **User Management System** built with **C# (.NET Console Application)**.  
The project demonstrates core programming concepts, clean code structure, and practical **Git & Gitflow** usage.

---

## 🚀 Features

- ➕ Add new users (Name, Age, Salary)
- 📋 Show all users
- 🔍 Search user by name
- 🗑️ Delete user
- 📊 Calculate average salary
- 🔢 Sort users by salary
- 💾 Save & load data from file (`users.txt`)
- ✅ Strong input validation
- 🧭 Clean & user-friendly menu UI

---

## 🛠️ Technologies & Tools

- **Language:** C#
- **Framework:** .NET Console App
- **Collections:** `List<T>`
- **File Handling:** `StreamWriter`, `File.ReadAllLines`
- **LINQ:** Average calculation
- **Version Control:** Git & GitHub
- **Workflow:** Feature branches + Merge + Release tag
